# PhotoSweep Google Photos Integration

This directory contains the Google Photos integration source built into PhotoSweep. It is maintained in this repository and does not require a Git submodule or a checkout from another repository.

From the PhotoSweep root, install its build dependencies and generate the userscript with:

```bash
npm --prefix Google-Photos-Toolkit ci
npm run build:gptk
```
