# Vendored Google Photos Toolkit

This directory contains the source snapshot PhotoSweep previously consumed as a Git submodule. It is now tracked and built from this repository.

- Source repository: https://github.com/xob0t/Google-Photos-Toolkit
- Imported commit: `cd1db961c6eacc5a3bc20304b559770ea152d930`
- This branch's parent repository previously pinned the same commit.
- Keep the original MIT license and copyright notice in [LICENSE](LICENSE).

PhotoSweep maintains this local snapshot. The package identity, userscript namespace, homepage, and support URL use PhotoSweep; upstream icon and download/update URLs were removed. The metadata build step embeds the original LICENSE in the generated userscript. API and application source files remain from the imported commit.
